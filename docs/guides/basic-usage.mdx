# Basic Usage

This guide covers the fundamental concepts and patterns for using FuzzyFilter.

## Creating a Filter Instance

The `createFuzzyFilter` factory function creates a new filter instance:

```typescript
import { createFuzzyFilter } from "@jasperhino/fuzzyfilter";

const filter = createFuzzyFilter();
```

You can pass configuration options:

```typescript
const filter = createFuzzyFilter({
  maxSuggestions: 15,      // Maximum suggestions to return
  debounceMs: 200,         // Debounce delay for suggestions
  benchmark: true,         // Enable performance telemetry
});
```

## Defining a Schema

The schema describes your data structure. FuzzyFilter uses this to generate intelligent suggestions.

```typescript
import { columnId } from "@jasperhino/fuzzyfilter";

filter.setSchema({
  columns: [
    // Enum column - finite set of values
    {
      id: columnId("status"),
      name: "Status",
      type: "enum",
      values: ["Open", "Closed", "In Progress", "Pending"],
    },

    // Number column
    {
      id: columnId("priority"),
      name: "Priority",
      type: "number",
    },

    // String column
    {
      id: columnId("title"),
      name: "Title",
      type: "string",
    },

    // Date column
    {
      id: columnId("createdAt"),
      name: "Created At",
      type: "date",
    },

    // Boolean column
    {
      id: columnId("isActive"),
      name: "Active",
      type: "boolean",
    },
  ],
});
```

## Indexing Data

Index your data to enable result counting:

```typescript
const data = [
  { status: "Open", priority: 1, title: "Fix bug", createdAt: new Date(), isActive: true },
  { status: "Closed", priority: 3, title: "Add feature", createdAt: new Date(), isActive: false },
  // ... more rows
];

filter.indexData(data);
```

When data changes, call `indexData` again to rebuild the index.

## Getting Suggestions

As the user types, call `suggest` to get filter suggestions:

```typescript
const suggestions = await filter.suggest("stat");
// → Suggestions for columns starting with "stat"

const suggestions = await filter.suggest("status eq");
// → Suggestions for "Status = [value]"

const suggestions = await filter.suggest("status eq op");
// → Suggestions matching "Open" for Status column
```

Each suggestion includes:

```typescript
interface FilterSuggestion {
  id: string;              // Unique identifier
  label: string;           // Display label
  resultCount: number;     // How many rows match
  type: SuggestionType;    // What kind of suggestion
  completion: string;      // Text to insert if selected
  // ... more fields
}
```

## Compiling Filters

Once the user completes their filter, compile it into a predicate:

```typescript
// From user input
const compiled = filter.compile("status eq Open");

// Use the predicate to filter data
const matches = data.filter(compiled.predicate);

// Access parsed filter info
console.log(compiled.column);    // "status"
console.log(compiled.operator);  // "eq"
console.log(compiled.value);     // "Open"
```

You can also compile programmatically:

```typescript
const compiled = filter.compileFilter("priority", "gte", 3);
const highPriority = data.filter(compiled.predicate);
```

## Working with Operators

FuzzyFilter supports many operators depending on the column type:

```typescript
// Equality
"status eq Open"           // Status equals Open
"status neq Closed"        // Status not equals Closed

// Comparison (number, date)
"priority gt 3"            // Priority greater than 3
"createdAt lte 2024-01-01" // Created before or on Jan 1

// String matching
"title contains bug"       // Title contains "bug"
"title startswith Fix"     // Title starts with "Fix"

// Set membership (enum)
"status in Open,Pending"   // Status is Open or Pending
"status notin Closed"      // Status is not Closed

// Range
"priority between 1,5"     // Priority between 1 and 5

// Null checks
"title isempty"            // Title is empty/null
"title isnotempty"         // Title has a value
```

## Natural Language Dates

Date columns support natural language:

```typescript
"createdAt eq today"
"createdAt gte yesterday"
"createdAt lte last week"
"createdAt between last month,today"
"createdAt eq 2 days ago"
```

Supported expressions include:
- `today`, `yesterday`, `tomorrow`
- `last week`, `this week`, `next week`
- `last month`, `this month`, `next month`
- `2 days ago`, `3 weeks from now`
- Standard date formats (`2024-01-15`, `January 15, 2024`)

## Suggestion Lifecycle

A typical suggestion flow:

1. **User types** → `"st"`
2. **Column suggestions** → `["Status", "Start Date"]`
3. **User types** → `"status "`
4. **Operator suggestions** → `["=", "≠", "in", "not in"]`
5. **User types** → `"status eq "`
6. **Value suggestions** → `["Open (5)", "Closed (3)", ...]`
7. **User completes** → `"status eq Open"`
8. **Compile and filter** → `filter.compile("status eq Open")`
