# FuzzyFilter

FuzzyFilter is a TypeScript library for building intelligent filter interfaces with natural language support. It provides fuzzy matching, instant counts, and smart suggestions for data table filtering.

## Key Features

<CardGroup cols={2}>
  <Card title="Fuzzy Matching" icon="magnifying-glass">
    Typo-tolerant search for columns, operators, and values. Type "stauts" and still find "Status".
  </Card>
  <Card title="Instant Counts" icon="chart-bar">
    Real-time result counts using optimized data structures. Know how many rows match before applying a filter.
  </Card>
  <Card title="Natural Language Dates" icon="calendar">
    Parse expressions like "last week", "yesterday", or "next month" automatically.
  </Card>
  <Card title="Type-Safe" icon="shield-check">
    Full TypeScript support for compile-time safety.
  </Card>
</CardGroup>

## Quick Example

```typescript
import { createFuzzyFilter, columnId } from "@jasperhino/fuzzyfilter";

// Create a filter instance
const filter = createFuzzyFilter();

// Define your schema
filter.setSchema({
  columns: [
    { id: columnId("status"), name: "Status", type: "enum", values: ["Open", "Closed", "Pending"] },
    { id: columnId("priority"), name: "Priority", type: "number" },
    { id: columnId("createdAt"), name: "Created At", type: "date" },
  ],
});

// Index your data
filter.indexData(myData);

// Get suggestions as the user types
const suggestions = await filter.suggest("stat eq");
// → [{ label: "Status = Open", resultCount: 5 }, ...]
```
