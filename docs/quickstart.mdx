# Quick Start

This guide will walk you through building a basic filter interface with FuzzyFilter.

## 1. Install the packages

<CodeGroup>

```bash npm
npm install @jasperhino/fuzzyfilter
```

```bash yarn
yarn add @jasperhino/fuzzyfilter
```

```bash pnpm
pnpm add @jasperhino/fuzzyfilter
```

```bash bun
bun add @jasperhino/fuzzyfilter
```

</CodeGroup>

For React or Vue, also install the framework-specific package:

<CodeGroup>

```bash React
npm install @jasperhino/fuzzyfilter fuzzyfilter-react
```

```bash Vue
npm install @jasperhino/fuzzyfilter fuzzyfilter-vue
```

</CodeGroup>

## 2. Create a filter instance

```typescript
import { createFuzzyFilter, columnId } from "@jasperhino/fuzzyfilter";

const filter = createFuzzyFilter();
```

## 3. Define your schema

The schema tells FuzzyFilter about your data structure:

```typescript
filter.setSchema({
  columns: [
    {
      id: "status",
      name: "Status",
      type: "enum",
      values: ["Open", "Closed", "In Progress", "Pending"],
    },
    {
      id: "priority",
      name: "Priority",
      type: "number",
    },
    {
      id: "title",
      name: "Title",
      type: "string",
    },
    {
      id: "createdAt",
      name: "Created At",
      type: "date",
    },
  ],
});
```

## 4. Index your data

```typescript
const myData = [
  { status: "Open", priority: 1, title: "Fix login bug", createdAt: new Date() },
  { status: "Closed", priority: 3, title: "Add dark mode", createdAt: new Date() },
  // ... more rows
];

filter.indexData(myData);
```

## 5. Get suggestions

```typescript
const suggestions = await filter.suggest("stat eq op");

// suggestions contains:
// [
//   { label: "Status = Open", resultCount: 5, ... },
//   { label: "Status = Open", resultCount: 5, ... },
// ]
```

## 6. Compile and execute filters

```typescript
// Compile from user input
const compiled = filter.compile("status eq Open");

// Use the predicate function to filter data
const matches = myData.filter(compiled.predicate);
```

## Framework Integration

### React

```tsx
import { useFuzzyFilter } from "fuzzyfilter-react";

function FilterBox({ filter }) {
  const { query, setQuery, suggestions, applySuggestion } = useFuzzyFilter(filter);

  return (
    <div>
      <input
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Type to filter..."
      />
      <ul>
        {suggestions.map((s) => (
          <li key={s.id} onClick={() => applySuggestion(s)}>
            {s.label} ({s.resultCount} results)
          </li>
        ))}
      </ul>
    </div>
  );
}
```

### Vue

```vue
<script setup lang="ts">
import { useFuzzyFilter } from "fuzzyfilter-vue";

const props = defineProps<{ filter: FuzzyFilter }>();
const { query, suggestions, applySuggestion } = useFuzzyFilter(props.filter);
</script>

<template>
  <div>
    <input v-model="query" placeholder="Type to filter..." />
    <ul>
      <li v-for="s in suggestions" :key="s.id" @click="applySuggestion(s)">
        {{ s.label }} ({{ s.resultCount }} results)
      </li>
    </ul>
  </div>
</template>
```
