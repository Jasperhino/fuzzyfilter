# Installation

FuzzyFilter is available on npm and can be installed with any package manager.

## Core Library

The core library provides all the filtering logic and can be used with any framework:

<CodeGroup>

```bash npm
npm install fuzzyfilter
```

```bash yarn
yarn add fuzzyfilter
```

```bash pnpm
pnpm add fuzzyfilter
```

```bash bun
bun add fuzzyfilter
```

</CodeGroup>

## Framework Packages

### React

For React applications, install the React hook package:

<CodeGroup>

```bash npm
npm install fuzzyfilter fuzzyfilter-react
```

```bash yarn
yarn add fuzzyfilter fuzzyfilter-react
```

```bash pnpm
pnpm add fuzzyfilter fuzzyfilter-react
```

```bash bun
bun add fuzzyfilter fuzzyfilter-react
```

</CodeGroup>

### Vue

For Vue 3 applications, install the Vue composable package:

<CodeGroup>

```bash npm
npm install fuzzyfilter fuzzyfilter-vue
```

```bash yarn
yarn add fuzzyfilter fuzzyfilter-vue
```

```bash pnpm
pnpm add fuzzyfilter fuzzyfilter-vue
```

```bash bun
bun add fuzzyfilter fuzzyfilter-vue
```

</CodeGroup>

## Additional Packages

### I18n Locales

For additional language support beyond English:

```bash
npm install @fuzzyfilter/i18n-locales
```

This package includes translations for:
- Spanish (`es`)
- French (`fr`)
- German (`de`)

### Operator Icons

Custom Lucide-style icons for filter operators:

```bash
# For React
npm install @fuzzyfilter/lucide-operators-react

# For Vue
npm install @fuzzyfilter/lucide-operators-vue
```

## Requirements

- **Node.js**: 18 or later
- **TypeScript**: 5.0 or later (optional but recommended)
- **React**: 18 or 19 (for fuzzyfilter-react)
- **Vue**: 3.0 or later (for fuzzyfilter-vue)

## TypeScript Setup

FuzzyFilter is written in TypeScript and includes type definitions. No additional `@types` packages are needed.

For the best experience, ensure your `tsconfig.json` includes:

```json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "bundler"
  }
}
```
